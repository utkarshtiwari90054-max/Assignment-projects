# Assignment 1.2 — Development Environment Setup

## Objective
To set up a web development environment using Visual Studio Code, Node.js, Live Server, and Prettier.

## 1. Install Visual Studio Code
Visual Studio Code (VS Code) is a free source-code editor developed by Microsoft. It is used to write and edit HTML, CSS, and JavaScript programs.

## 2. Install Node.js (LTS Version)
Node.js is a JavaScript runtime environment that allows JavaScript code to run outside a web browser. The LTS (Long-Term Support) version is recommended because it provides stability and regular updates.

## 3. Install Live Server and Prettier Extensions
- **Live Server:** It runs HTML files on a local development server and automatically refreshes the browser when changes are saved.
- **Prettier:** It is a code formatter that automatically formats code and makes it clean and readable.

Both extensions can be installed from the Extensions Marketplace in VS Code.

## 4. Create a Project Folder
A folder named `web-development-practice` was created to store all the web development files.

## 5. Create HTML, CSS, and JavaScript Files
The following three files were created inside the project folder:

1. `index.html` – Used to create the structure of a webpage.
2. `style.css` – Used to design and style the webpage.
3. `script.js` – Used to add functionality and interactivity to the webpage.

## 6. Run the HTML File Using Live Server
The `index.html` file was opened in Visual Studio Code. By right-clicking the file and selecting **Open with Live Server**, the webpage was successfully opened in the web browser.

## 7. Verify Node.js and npm Installation
The following commands were executed in the VS Code terminal:

**Command 1:**
```bash
node -v
```
It displays the installed Node.js version.

**Command 2:**
```bash
npm -v
```
It displays the installed npm version.

If both commands display version numbers, the installation is successful.
